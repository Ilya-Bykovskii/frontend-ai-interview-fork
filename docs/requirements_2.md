> Поиск с debounce. Сортировка кликом по заголовку колонки: по возрастанию → по убыванию → без сортировки. Сортировать можно по названию, цене, скидке, остатку и рейтингу.

**Функционал, обязательно:**

- Поле поиска с задержкой ~300 мс.
- Клик по заголовку сортируемой колонки переключает: по возрастанию → по убыванию → без сортировки. В заголовке виден индикатор направления.
- Сортировка одна: клик по другой колонке сбрасывает предыдущую.
- Сортирует сервер (`sortBy` и `order`), поиск и сортировка работают вместе.
- Всегда показан результат последнего запроса: устаревшие ответы отменяются или игнорируются.
- Пустой результат: «Ничего не найдено». Очистка поиска возвращает все товары.

**Функционал, желательно:**

- Во время нового запроса старые строки остаются на экране (приглушённые), таблица не мигает в пустоту.
- Заголовки — кнопки с `aria-sort`.
- При загрузке страницы нет лишнего запроса, в том числе из-за двойного эффекта в `StrictMode`.
