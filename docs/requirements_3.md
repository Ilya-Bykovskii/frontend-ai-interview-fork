**Требование:**

> Фильтр по категории (список из `/products/category-list`). Я хочу скинуть коллеге ссылку, и он должен увидеть ту же таблицу: тот же поиск, ту же сортировку, ту же категорию. Кнопки «Назад» и «Вперёд» в браузере работают.

**Функционал, обязательно:**

- Выбор категории с вариантом «Все категории». Названия читаемые: `smartphones` → «Smartphones».
- Категория работает **вместе** с поиском и сортировкой. ~~Это ловушка: сервер категорию в поиске игнорирует, кандидат должен заметить и решить.~~
- URL хранит поиск, сортировку и категорию. Ссылка в новой вкладке восстанавливает контролы и таблицу.
- «Назад» и «Вперёд» переключают состояния фильтров, история «вперёд» не теряется.
- Неизвестные значения в URL сбрасываются на значения по умолчанию, приложение не падает.

**Функционал, желательно:**

- Набор текста не создаёт запись в истории на каждую паузу.
- В URL нет параметров со значениями по умолчанию. 
- Источник правды один: состояние выводится из URL, а не синхронизируется туда и обратно.
