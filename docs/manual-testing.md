# Чеклист ручного тестирования

Покрывает требования `docs/requirements_1.md`–`docs/requirements_3.md` и решения из `docs/ARCHITECTURE.md`.

## Подготовка

- Node 22.22.1: `nvm use 22.22.1`.
- `npm run dev`, открыть http://localhost:5173.
- DevTools → Network, фильтр `dummyjson`.

## Таблица и модалка

- [ ] Открыть `/`: 20 строк; у товаров groceries в колонке «Бренд» — «—»; цены, скидки, остаток и рейтинг выровнены вправо; статусы по-русски.
- [ ] Клик по строке: открывается модалка со всеми разделами (описание, теги, изображения, характеристики, условия покупки, служебная информация, отзывы), в URL появляется `productId`.
- [ ] Закрытие кнопкой «Закрыть», кликом по фону и клавишей Esc: модалка закрывается, `productId` уходит из URL, остальные параметры остаются.
- [ ] Tab до строки → Enter → Esc: фокус возвращается на ту же строку; пока модалка открыта, Tab не выводит фокус за её пределы.
- [ ] Открыть модалку и нажать «Назад» в браузере: модалка не закрывается отдельным шагом истории, открывается предыдущее состояние фильтров.

## Поиск

- [ ] Ввести «phone»: запрос уходит через ~300 мс после последней буквы, в Network один запрос.
- [ ] Продолжить ввод с паузами, затем один раз «Назад»: открывается состояние до начала набора, а не промежуточный вариант.
- [ ] Ввести «zzzz»: «Ничего не найдено».
- [ ] Очистить поле (крестик или Backspace): возвращаются все товары, `q` уходит из URL.

## Сортировка

- [ ] Три клика по «Цене»: стрелка вверх (по возрастанию) → стрелка вниз (по убыванию) → без стрелки (исходный порядок).
- [ ] Сортировка по «Цене», затем клик по «Рейтингу»: стрелка у цены пропадает, сортировка только по рейтингу.
- [ ] Колонки «Категория», «Бренд», «Статус» не кликаются.
- [ ] Поиск «phone» + сортировка по цене: найденные товары отсортированы по цене.

## Категория

- [ ] Список категорий: первый пункт «Все категории», дальше читаемые названия («Home decoration»).
- [ ] «Smartphones» при поиске «phone»: в таблице только смартфоны.
- [ ] Вернуть «Все категории»: `category` уходит из URL.

## URL и история

- [ ] Настроить поиск, категорию и сортировку, скопировать URL, открыть в новой вкладке: поле, селект, стрелка и таблица совпадают.
- [ ] Сделать несколько изменений, пройти «Назад» до конца и «Вперёд» обратно: каждый шаг восстанавливает контролы, история «вперёд» не теряется.
- [ ] Открыть `/?sortBy=foo&order=up&category=nope&q=%20`: приложение не падает, URL очищается до `/`, показаны все товары.
- [ ] Открыть `/?productId=999`: в модалке «Product with id '999' not found» и кнопка «Повторить».

## Загрузка и ошибки

- [ ] Троттлинг Slow 4G и смена сортировки: старые строки остаются приглушёнными, сверху полоса загрузки, таблица не пустеет.
- [ ] Два быстрых клика по одной сортировке: первый запрос в Network отменён (canceled), в таблице результат второго.
- [ ] Перезагрузка в dev-режиме: по одному запросу на категории и на товары, без дублей.
- [ ] Request blocking для `dummyjson.com` + перезагрузка: «Не удалось загрузить категории» и «Не удалось связаться с сервером», обе с кнопкой «Повторить». Снять блокировку, нажать обе кнопки: данные загружаются.
